## AI tools & tips

- **ChatGPT — Projects as a work folder** — Drop related chats, custom instructions and files into one Project so every new chat already knows your context (e.g. “Bangkok morning brief style, en-GB”). Try: New Project → add instructions + 1–2 sample briefs → start the next draft inside that Project.
- **ChatGPT — Canvas for editable drafts** — For longer handover text, ask ChatGPT to open Canvas, then edit section-by-section in the side panel instead of regenerating the whole thing. Try: “Put this brief in Canvas and tighten World news to 4 bullets.”
- **Claude — Projects + custom instructions** — Create a Claude Project with your section order and “list-only competitions, free entry only” rules once; upload yesterday’s `latest.md` so today’s draft matches tone. Try: Project instructions = section list + en-GB → upload prior brief → “Draft Saturday using this structure.”
- **Claude — Artifacts for a scannable one-pager** — Ask Claude to build a simple HTML layout of the brief (headings + bullets) you can skim on your phone. Try: “Make a clean one-page HTML of these 10 sections I can open offline.”
- **Grok Bot — `/handover` for a clean thread** — When a chat gets long, run `/handover` to summarise decisions and open context for a fresh thread so you don’t re-explain. Try it at the end of a planning chat before the next task.

## Expat life

- **THIM official launch (25 Sep)** — Download is optional; use it for TDAC if you prefer an app — it does **not** replace the TDAC requirement. Future hub for extensions and 90-day reports. Affects all foreign nationals. [VisasNews](https://visasnews.com/en/thailand-thim-app-officially-launches-after-pilot-phase/)
- **Suvarnabhumi eGates — 33 nationalities** — Returning visa-exempt travellers (incl. UK, Australia, Canada, most EU, Japan, Korea, Singapore, Hong Kong, UAE) with prior biometrics on the same passport and a completed TDAC. **Not** US/China/Taiwan/India; first-timers and visa holders (incl. DTV) still use staffed desks. [Deep Arrival](https://deeparrival.com/news/bangkok-suvarnabhumi-egates-33-nationalities-september-2026/)
- **Visa-exemption reset still in force since 15 Sep** — The old 60-day exemption is gone for new arrivals: mainly **30-day** tourism exemption (60 countries); Mauritius/Seychelles **15 days**; VoA shrunk to Azerbaijan, Belarus and Serbia. Long-stayers should use proper visas (DTV, retirement, Non-B, LTR, etc.). [KPMG](https://kpmg.com/xx/en/our-insights/gms-flash-alert/2026/flash-alert-2026-241.html) · [The Thaiger](https://thethaiger.com/guides/visa-information/thailand-visa-rules-2026-september-15)
- **Practical takeaway this weekend** — Complete TDAC before any arrival or re-entry; if you hold a UK (or other listed) passport with a prior stay on the same passport, try eGates at BKK — keep any control slip with your passport.
