- **Jargon: what is MCP?** — MCP (Model Context Protocol) is a shared “plug socket” so an AI assistant can discover and use outside tools and data — calendars, files, browsers, company apps — without each vendor inventing a private integration. Think of the model as the brain and MCP as a standard way for that brain to pick up tools safely. The Grok SDK above talks to remote MCP; DevDay also floated “MCP Events” so automations start when something happens in a connected app. When a brief says agents are “calling tools,” MCP is often the wiring underneath.
