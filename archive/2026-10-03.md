- **Jargon: what is an API?** — An API is a published way for one program to ask another program for something, and get a structured answer back — not a website you browse. A bot or a Twitter/X agent does not “read the app” the way you do. It calls an API: send this text to Grok, post this reply, search these posts. The experimental Grok SDK above is just a tidy wrapper around those calls. If a bot suddenly stops, the usual causes are a bad or leaked key, a rate limit (too many calls), or the API changing shape — which is why a pre-1.0 SDK tells you to pin a version. You never paste a secret API key into a browser or a public chat.

## AI tools & tips

- **ChatGPT — lock en-GB and “no invented numbers”** — Stop a pasted brief growing extra figures. Try: Settings → Personalization → Custom instructions → “Write en-GB. If a number is not in the text I paste, say you do not have it.”
- **Claude — one-line umbrella call** — Paste today’s Rain paragraph. Try: “One sentence: umbrella between 12:00 and 18:00, yes or no, and quote the peak %.”
- **Grok Bot — decode a bot error** — When an agent dies, ask what actually broke. Try: paste the error → “Plain English: is this an API key, a rate limit, or the bot’s own instructions? One next step.”
- **ChatGPT — temporary chat for a visa question** — Keep old trips out of a one-off answer. Try: Temporary chat → “UK passport, visa-exempt vs DTV for Thailand. Only rules you can point at. Do not draft a form.”
- **Claude — photograph a paper menu** — Useful when the board is in Thai. Try: photo → “en-GB: vegetarian dishes, anything with fish sauce or shrimp paste, and one question to ask the server.”
