## AI tools & tips

- **Grok Bot — `/handover` for a fresh thread** — When a chat gets long or messy, `/handover` summarises it so you can start clean without losing the plot. Try: in Morning (or any Bot chat) type `/handover` → open a new thread with the summary pinned as context.
- **ChatGPT — Temporary Chat for visa/banking asks** — Temporary Chat doesn’t land in history or update memory — handy for passport numbers, flight bookings or immigration questions. Try: new chat → Temporary Chat → “Translate this Thai immigration notice and say if I need to act today.”
- **Claude — turn Travel into a tick-list** — Paste today’s Travel + Expat bullets and ask for a short checklist you can skim before leaving home. Try: paste those two sections → “Make a 6-item en-GB checklist for my Bangkok airport run today; one line each.”
- **ChatGPT — photo translate a flood/road notice** — Snap a Thai street or BMA notice and ask what it means for drivers or pedestrians. Try: upload the photo → “Translate and tell me if this road is closed to cars.”
- **Grok Bot — ask Morning to hide in the sidebar** — If the chat list is crowded, you can hide an assistant and still reach it via Cmd-K / Hidden chats. Try: “Hide yourself from the sidebar but keep the morning routine” → confirm in settings if offered.
