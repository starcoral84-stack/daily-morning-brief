## AI tools & tips

- **ChatGPT — scheduled Tasks for recurring jobs** — On Plus/Pro, set a Task so ChatGPT runs a prompt on a schedule (e.g. “every weekday 6am: summarise overnight AI headlines for a Bangkok morning brief”). Try: Settings → Tasks (or ask “Create a daily Task that…”) → set time + timezone Asia/Bangkok → review the first run.
- **ChatGPT — Memory + custom instructions** — Turn on Memory and add lasting prefs once (“en-GB, Bangkok, list-only free-entry competitions”) so you don’t restate them every chat. Try: Settings → Personalisation → Custom instructions + Memory on → ask “What do you remember about me?” and prune anything stale.
- **Claude — Design for decks and prototypes** — Ask Claude Design to turn bullet notes into a slide deck or clickable mock-up (handy for sharing a one-page brief overview). Try: open Design → paste today’s section list → “Make a clean 10-slide deck, one section per slide.”
- **Grok Bot — routines / schedules** — Set a recurring routine so the Bot compiles or reminds you without a new chat each time (your morning handover already runs on a 6:11 AM Bangkok schedule). Try: ask Grok Bot to “schedule a daily reminder at 6:05 to open the latest brief” or adjust an existing routine.
- **Claude / ChatGPT — file upload for analysis** — Drop a PDF, CSV or yesterday’s `latest.md` and ask for a diff-style update (“What’s new vs yesterday? Keep the same section order.”). Try: upload `/latest.md` → “Draft Sunday using this structure; flag any stale events.”

- **Practical takeaway** — Complete TDAC before any arrival/re-entry; eligible UK (and other listed) returnees can try eGates at BKK when flood delays ease — keep any control slip with your passport.
