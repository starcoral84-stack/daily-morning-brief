AI tools & tips

ChatGPT — Projects as a work folder — Drop related chats, custom instructions and files into one Project so every new chat already knows your context (e.g. “Bangkok morning brief style, en-GB”). Try: New Project → add instructions + 1–2 sample briefs → start the next draft inside that Project.

ChatGPT — Canvas for editable drafts — For longer handover text, ask ChatGPT to open Canvas, then edit section-by-section in the side panel instead of regenerating the whole thing. Try: “Put this brief in Canvas and tighten World news to 4 bullets.”

Claude — Projects + custom instructions — Create a Claude Project with your section order and “list-only competitions, free entry only” rules once; upload yesterday’s latest.md so today’s draft matches tone. Try: Project instructions = section list + en-GB → upload prior brief → “Draft Saturday using this structure.”

Claude — Artifacts for a scannable one-pager — Ask Claude to build a simple HTML layout of the brief (headings + bullets) you can skim on your phone. Try: “Make a clean one-page HTML of these 10 sections I can open offline.”

Grok Bot — /handover for a clean thread — When a chat gets long, run /handover to summarise decisions and open context for a fresh thread so you don’t re-explain. Try it at the end of a planning chat before the next task.
